# Data Moat

> مزیت رقابتی پایدار Granovo: داده‌ی «ترکیب ورودی ← پارامتر ← کیفیت خروجی» که از کارخانه‌های
> واقعی ایران جمع‌آوری می‌شود.

## چرا مهم است
فناوری‌های خارجی معمولاً روی یک پلیمر خاص و دستگاه‌های استاندارد متمرکزند. پلاستیک ورودی
کارخانه‌های ایران ناهمگن‌تر است و دستگاه‌های بومی خاص خودشان را دارند — داده‌ی بومی این
gap را می‌بندد و رقبا نمی‌توانند به‌راحتی کپی کنند.

## چرخه‌ی تقویت
هرچه کارخانه‌های بیشتری بپیوندند → داده‌ی بیشتر → [[entities/extruder-parameter-predictor]]
دقیق‌تر → نرخ رد کالای پایین‌تر → جذابیت بیشتر برای کارخانه‌های جدید (network effect داده‌محور).
