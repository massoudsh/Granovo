# Polymer Identification

> ماژول شناسایی لحظه‌ای نوع و خلوص پلیمر در جریان ورودی با تصویربرداری طیفی و بینایی ماشین.

## مسئولیت‌ها
- تشخیص نوع پلیمر (PET, HDPE, PP, ...) در جریان ورودی خط تولید
- برآورد خلوص/آلودگی مواد ورودی
- خروجی این ماژول ورودی مستقیم [[entities/extruder-parameter-predictor]] است

## وابستگی‌ها
- [[concepts/data-moat]] — داده‌ی خروجی این ماژول بخشی از دیتاست «ترکیب ← پارامتر ← کیفیت» است

## قراردادها / Edge cases
- ورودی ناهمگن (چند نوع پلیمر مخلوط) باید به‌صورت درصد ترکیب گزارش شود، نه فقط یک برچسب.
- دقت تشخیص در پلاستیک‌های آلوده/رنگی نیاز به دیتاست آموزشی جداگانه دارد.
